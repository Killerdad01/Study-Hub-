# StudyFlow — HTML to APK

This project wraps the StudyFlow `index.html` app inside a native Android WebView.

## Build on GitHub

1. Upload this whole project to a GitHub repository.
2. Commit the files to the `main` branch.
3. Open the repository's **Actions** tab.
4. Select **Build StudyFlow APK** if needed.
5. The workflow builds `app-debug.apk`.
6. Open the completed workflow run and download the artifact named `StudyFlow-debug-apk`.
7. Extract the ZIP and install the APK on Android.

The web app is stored at:
`app/src/main/assets/index.html`
